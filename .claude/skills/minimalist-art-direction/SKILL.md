# Minimalist Art Direction for ICG

## Goal

Give ICG a restrained contemporary visual identity.

The direction should combine:

- minimalism
- editorial web design
- digital studio aesthetics
- strong typography
- carefully selected imagery
- subtle ICG branding

The site should feel intentionally designed,
not automatically generated.

## Overall aesthetic

Think:

independent creative studio
modern architecture magazine
editorial portfolio
digital design showcase

NOT:

AI SaaS
crypto
cyberpunk
gaming
developer dashboard

## Color

Main background:

near-black / graphite.

Primary typography:

white / warm white.

Secondary typography:

neutral gray.

ICG blue → violet gradient should be treated as a branding accent.

Do NOT spread the gradient everywhere.

Preferred approximate ratio:

85–90% neutral colors
10–15% brand accent

Accent should appear selectively in:

- logo
- small interaction details
- occasional line
- selected CTA
- project metadata
- subtle highlight

Do not make every important object blue.

## Typography

Typography should carry a large part of the visual identity.

Use:

- strong editorial headings
- carefully controlled line lengths
- noticeable scale contrast
- clean body text
- intentional whitespace

Avoid:

- excessive bold text
- gradient typography
- tiny fake-technical labels everywhere
- all-caps labels in every section

Large headings should not automatically be centered.

Prefer left alignment when appropriate.

## Images and art direction

ICG sells websites.

Therefore imagery should focus on:

1. website projects
2. client industries
3. carefully composed design details
4. editorial photography

Use large visuals instead of many small decorative graphics.

Possible visual material:

- beauty salon interiors
- fashion/beauty closeups
- architecture
- materials and textures
- editorial portraits when appropriate
- product/interface screenshots
- cropped website compositions
- print-like typography layouts
- abstract photography

Images should feel curated.

Avoid:

- generic smiling stock-business teams
- handshake photos
- laptops on desks
- fake corporate meetings
- random AI 3D objects
- abstract neon shapes
- robots
- generic "technology" imagery

## Project imagery

Portfolio images should feel like art-directed presentations.

Examples:

- full browser screenshot
- cropped close-up of typography
- mobile interface crop
- website on an editorial background
- image + typography composition
- browser screenshot partially extending beyond viewport
- project image occupying 60–80% of the section

Do not place every screenshot inside a floating glass card.

## Decorative photography

It is acceptable to add carefully selected decorative imagery,
but it must support the brand.

Every image must answer:

"Why is this image here?"

If it is only filling empty space:
remove it.

## Image density

Prefer:

one strong image

instead of:

five weak decorative images.

Allow sections to breathe.

## Layout rhythm

Alternate between:

dense content
open whitespace
large image
short text
large image
small metadata

Do not make every section the same height.

## Animation

Animation should be nearly invisible.

Use:

subtle reveal
image clipping
slight movement
gentle opacity changes
small hover transitions

Avoid:

floating UI objects
continuous bobbing
large parallax
glowing animations
particles
dramatic rotations

## Hero guidance

The ICG hero should NOT look like a SaaS dashboard.

Avoid:

gradient text
floating status cards
fake system indicators
huge glowing button
random browser chrome

Possible direction:

left side:
ICG
strong slogan
very short supporting text

right / bottom:
one highly art-directed project preview

or:

large editorial typography combined directly with a project screenshot.

The work itself should be the hero visual.

## Final test

Ask:

Would a professional design studio plausibly publish this?

Does it look deliberate when all animations are disabled?

Would the composition still work in grayscale?

Would it remain recognizable without gradients?

If not:
the underlying composition is not strong enough.
