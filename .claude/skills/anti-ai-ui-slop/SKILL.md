# Anti AI UI Slop

## Purpose

Detect and remove visual patterns that make a website look obviously AI-generated, template-generated, or like a generic modern SaaS landing page.

The goal is NOT to make the interface boring.

The goal is to make it feel:

- art-directed
- deliberate
- recognizable
- restrained
- human-designed
- brand-specific

## Core principle

When a design looks generic, solve the composition first.

Do NOT automatically solve weak design by adding:

- gradients
- glow
- glassmorphism
- floating cards
- badges
- pills
- abstract blobs
- animations
- borders around everything

Reduction is often better than addition.

## Common AI-slop patterns

Aggressively detect:

### Typography

- one gradient-colored word inside a giant headline
- huge generic sans-serif hero text
- tiny uppercase monospace eyebrow labels
- excessive letter spacing
- generic startup copy
- every section using the same heading pattern

Avoid copy such as:

"Elevate your business"
"Transform your digital presence"
"Built for the future"
"Next-generation experience"
"Powerful digital experiences"
"From idea to reality"

### Buttons

Avoid:

- glowing blue CTA buttons
- large gradient buttons
- strong button shadows
- arrows on every CTA
- multiple primary CTAs
- overly rounded buttons

### Cards

Avoid excessive:

- rounded containers
- glass cards
- 16–24px radius everywhere
- faint white border around every object
- icon + title + paragraph cards repeated in grids
- fake technical status cards

Examples of suspicious labels:

READY
FAST
SECURE
AI POWERED
MOBILE READY
OPTIMIZED

### Hero sections

Flag:

- generic browser mockup directly below hero text
- random floating UI status cards
- giant glow behind screenshot
- gradient text
- decorative grid
- perspective screenshot without a reason
- meaningless product status indicators

### Decoration

Avoid excessive:

- purple/blue glow blobs
- radial glow everywhere
- aurora backgrounds
- blurred neon
- dot grids
- particles
- random 3D shapes
- glowing borders

## ICG-specific direction

ICG is a small web design and development studio.

It must NOT visually resemble:

- AI startup
- crypto company
- developer tool
- cybersecurity product
- generic SaaS landing page

ICG should feel closer to:

- an independent digital studio
- an editorial design portfolio
- a small contemporary creative agency

The actual website work should create visual interest.

Prefer:

- strong typography
- large project visuals
- restrained brand color
- asymmetrical composition
- strong whitespace
- editorial rhythm
- fewer UI decorations

## Audit questions

Ask:

- Could this design belong to 100 SaaS companies?
- Would I recognize ICG without seeing the logo?
- Is visual interest coming from composition or effects?
- Are there too many cards?
- Are gradients compensating for weak design?
- Does every visual element communicate something?

If the result feels generic, redesign it.
