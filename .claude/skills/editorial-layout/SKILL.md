# Editorial Web Layout

## Goal

Create visual hierarchy using composition rather than repetitive UI cards.

Avoid repeating this pattern:

eyebrow
heading
paragraph
three cards

throughout the entire website.

## Use varied compositions

Possible structures:

- large typography + visual
- 30/70 split layout
- large full-width project
- oversized project title
- sticky text with scrolling visuals
- image followed by compact metadata
- typography-only section
- asymmetrical project showcase
- horizontal process
- large before/after composition
- project index
- alternating editorial layouts

## Cards

Before creating any card ask:

"Does this information actually need a container?"

If no:
do not create a card.

Use:

spacing
alignment
typography

instead.

## Borders

Borders should define real structure.

Do not outline every block.

## Radius

Do not apply the same rounded radius everywhere.

Browser previews:
small or moderate radius.

Buttons:
moderate radius.

Editorial text:
no container needed.

## Portfolio

ICG's work should be visually dominant.

Prefer:

PROJECT NUMBER
PROJECT NAME
CATEGORY

large image

small metadata

short explanation

instead of:

small thumbnail card
title
description
button
