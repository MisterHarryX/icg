# Reference Driven Design

## Primary reference

The primary design reference for ICG is:

https://writelite-web.vercel.app/ru

You MUST inspect the actual live website when performing visual redesign work.

Do not reduce the reference to vague adjectives such as:

"dark"
"modern"
"premium"

Analyze real design decisions.

## Study

Inspect:

- content width
- page margins
- section spacing
- typography hierarchy
- paragraph width
- header behavior
- border frequency
- radius sizes
- navigation density
- button dimensions
- visual rhythm
- accent color frequency
- animation distance
- animation duration
- section composition
- mobile adaptation
- relationship between text and product visuals

## Important

DO NOT clone WriteLite.

Do not copy:

- text
- branding
- exact sections
- exact UI components

Extract principles.

For every design decision use:

REFERENCE PRINCIPLE:
What WriteLite does successfully.

ICG ADAPTATION:
How this should work for a web studio.

## Priority

Prioritize:

1. typography
2. composition
3. spacing
4. hierarchy
5. restraint
6. interaction
7. decorative effects

Effects come last.

If ICG starts looking more like:

- generic SaaS
- Linear clone
- Vercel clone
- AI startup
- crypto project

stop and reconsider the composition.
